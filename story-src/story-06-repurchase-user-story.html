复购率 = 复购用户数 / 有购买行为的用户数
复购用户：购买次数 >= 2 的用户  |  本案例采用 90天复购率
SQL
-- 计算90天复购率
SELECT
    COUNT(DISTINCT user_id) as total_users,
    SUM(CASE WHEN order_count >= 2 THEN 1 ELSE 0 END) as repeat_users,
    SUM(CASE WHEN order_count >= 2 THEN 1 ELSE 0 END) * 1.0
        / COUNT(DISTINCT user_id) as repeat_rate
FROM (
    SELECT
        user_id,
        COUNT(DISTINCT order_id) as order_count
    FROM orders
    WHERE order_date BETWEEN '2024-01-01' AND '2024-03-31'
    GROUP BY user_id
) t;

CHAPTER 05

用户分群分析

从首单时间、首单金额、首单品类、购买渠道四个维度拆解用户群体。

按首单时间分群
新用户复购率明显低于老用户

关键发现

新用户复购率明显低于老用户。3月新用户复购率只有18%，远低于1月老用户的32%。

按首单金额分群
首单金额越高，复购率越高

关键发现

首单金额越高，复购率越高。>500元的高端用户复购率达42%，而<100元的低门槛用户仅15%。

按首单品类分群
清仓品用户的复购率最低

关键发现

清仓品用户的复购率最低（12%），外套用户复购率最高（38%）。高单价品类用户的忠诚度更高。

按渠道分群
广告投放和活动引流的用户复购率最低

关键发现

自然搜索用户复购率最高（35%），活动引流用户最低（15%）。主动需求的用户忠诚度更高。

CHAPTER 06

行为差异分析

对比复购用户和非复购用户的行为特征，找出关键差异。

复购用户 vs 非复购用户 行为对比
复购用户在首单金额、活跃度、互动意愿上显著更高

关键发现

- 复购用户的首单金额更高（380元 vs 220元）、品类更多（1.8个 vs 1.2个）
- 复购用户在首单后更活跃（7天内访问4.2次 vs 1.5次）
- 复购用户更愿意参与互动（关注公众号65% vs 25%，领取会员卡58% vs 22%）

复购时间分布
70%的复购发生在首单后30天内

核心洞察

70%的复购发生在首单后30天内。首单后7-30天是复购的关键窗口。

首单体验与复购
售后问题严重影响复购率
会员权益与复购
会员权益显著提升复购率

关键发现

- 有投诉的用户复购率仅8%，体验严重受损
- 高级会员复购率48%，比非会员高30个百分点
- 会员权益是有效的复购激励

CHAPTER 07

关键发现

通过用户分群和行为分析，小林找到了复购率低迷的根因。

🆕

发现1：新用户复购率最低

3月新用户复购率只有18%，远低于1月老用户的32%。新用户是复购提升的重点群体。

🛒

发现2：首单体验决定复购

首单金额高、品类多的用户复购率高。有售后问题的用户复购率大幅下降。

⏰

发现3：30天是关键窗口

70%的复购发生在首单后30天内。首单后7-30天是复购的关键窗口。

💎

发现4：会员权益有效提升复购

会员复购率比非会员高14-30个百分点。会员权益是有效的复购激励。

📢

发现5：渠道质量影响复购

自然搜索用户复购率最高（35%），广告和活动用户复购率最低（15-20%）。

业务建议

基于分析发现，制定短、中、长期三阶段提升策略。

短期建议
1. 新用户首单后30天触达

首单后7天：发送优惠券，引导二次购买
首单后14天：推送新品/活动信息
首单后30天：大额优惠券，挽回流失风险

2. 优化首单体验

降低首单退货率：优化商品描述、尺码建议
快速处理售后问题：减少投诉
首单好评激励：提升满意度

3. 引导会员注册

首单后引导注册会员
会员专属优惠券
会员积分体系

1. 分渠道差异化运营

活动用户：转化为会员，提升忠诚度

2. 建立复购预警机制

主动触达，提供优惠挽回

3. 优化会员体系

新用户期：引导首单后复购

CHAPTER 10

方法论总结

用户分群思维——将用户按照特定维度划分为不同群体，分析各群体的特征和差异，制定针对性的策略。

用户分群的维度

维度类型 具体维度
行为维度购买频次、金额、品类
属性维度年龄、性别、城市
时间维度注册时间、首单时间
来源维度渠道、活动

用户分群的价值

1. 发现差异
不同群体的行为差异

2. 定位问题
哪个群体表现异常

3. 精准运营
针对不同群体制定策略

用户分群的四大注意

❶ 分群要有意义：群体之间要有明显差异
❷ 群体规模要合理：太小没有统计意义，太大不够精细
❸ 关注群体变化：用户可能从一个群体迁移到另一个群体
❹ 策略要可执行：分群后要能制定针对性的策略

指标分析时 策略制定时 效果评估时 用户运营时
