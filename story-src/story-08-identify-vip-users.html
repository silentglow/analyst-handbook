CHAPTER 04

RFM模型介绍

◆ RFM模型定义

RFM模型是一种经典的用户价值分析模型，通过三个维度来衡量用户价值。

维度 英文 含义 业务意义
R Recency 最近一次消费时间 用户活跃度
F Frequency 消费频次 用户忠诚度
M Monetary 消费金额 用户贡献度

RFM模型的价值

  • 多维度评估：不只看金额，还看活跃度和忠诚度
  • 可操作性强：每个维度都能对应到运营动作
  • 经典可靠：被广泛验证，适用于大多数零售/电商场景

RFM分层逻辑

将每个维度分为高、低两档，得到8类用户：

用户类型 R F M 特征 运营策略
重要价值用户 高高高 最近消费、频次高、金额高 VIP服务、专属权益
重要发展用户 高低高 最近消费、频次低、金额高 提升频次、会员激励
重要保持用户 低高高 较久未消费、频次高、金额高 唤醒激活、关怀触达
重要挽留用户 低低高 较久未消费、频次低、金额高 重点挽回、优惠刺激
一般价值用户 高高低 最近消费、频次高、金额低 提升客单、交叉销售
一般发展用户 高低低 最近消费、频次低、金额低 培养习惯、引导复购
一般保持用户 低高低 较久未消费、频次高、金额低 维护关系、防止流失
一般挽留用户 低低低 较久未消费、频次低、金额低 低成本维护或放弃
CHAPTER 05

数据准备与RFM计算

数据来源

SQL 
-- 用户消费数据
SELECT
    user_id,
    MAX(order_date) as last_order_date,           -- 最近消费时间
    COUNT(DISTINCT order_id) as order_count,       -- 消费频次
    SUM(order_amount) as total_amount              -- 消费金额
FROM orders
WHERE order_status = 'completed'
GROUP BY user_id;

样本数据

RFM值计算

Python 
import pandas as pd
from datetime import datetime

# 计算R值（天数越小，R值越高）
reference_date = datetime(2024, 3, 31)
df['R'] = (reference_date - pd.to_datetime(df['last_order_date'])).dt.days

# F值直接使用order_count
df['F'] = df['order_count']

# M值直接使用total_amount
df['M'] = df['total_amount']
CHAPTER 06

RFM打分方法

将R、F、M值转换为1-5分，使用分位数法进行打分：

Python 
# R值打分（天数越小，分数越高）
df['R_score'] = pd.qcut(df['R'], 5, labels=[5, 4, 3, 2, 1])

# F值打分（频次越高，分数越高）
df['F_score'] = pd.qcut(df['F'], 5, labels=[1, 2, 3, 4, 5])

# M值打分（金额越高，分数越高）
df['M_score'] = pd.qcut(df['M'], 5, labels=[1, 2, 3, 4, 5])

打分标准

分数 R（天数） F（频次） M（金额）
5 ≤7天 ≥10次 ≥5000元
4 8-14天 7-9次 3000-4999元
3 15-30天 4-6次 1500-2999元
2 31-60天 2-3次 500-1499元
1 >60天 1次 <500元

CHAPTER 07

用户分层逻辑

以平均分为界，确定每个维度的高低阈值，然后将用户归入8个类别：

Python 
# 计算各维度平均分
R_mean = df['R_score'].mean()
F_mean = df['F_score'].mean()
M_mean = df['M_score'].mean()

# 判断高低
df['R_level'] = df['R_score'].apply(lambda x: '高' if x >= R_mean else '低')
df['F_level'] = df['F_score'].apply(lambda x: '高' if x >= F_mean else '低')
df['M_level'] = df['M_score'].apply(lambda x: '高' if x >= M_mean else '低')

方法论总结

◆ RFM模型

RFM模型通过 Recency（最近消费时间）、Frequency（消费频次）、Monetary（消费金额）三个维度来衡量用户价值，将用户分为8个层级，实现差异化运营。

RFM模型的优势

  • 多维度：不只看金额，综合评估用户价值
  • 可操作：每个维度都能对应到运营动作
  • 经典可靠：被广泛验证，适用于大多数场景

RFM模型的局限

  • 只看交易数据：不考虑用户行为、互动等
  • 静态分析：不反映用户价值的变化趋势
  • 阈值敏感：不同的打分标准会影响分层结果

RFM模型扩展

  • RFM-L：增加用户生命周期
  • RFM-P：增加用户潜力
  • RFM-A：增加用户活跃度

适用场景

  • 用户分层：识别高价值用户
  • 精准营销：针对不同层级制定策略
  • 流失预警：识别流失风险用户
  • 资源分配：合理分配运营资源
⚠️ 注意事项
  1. 打分标准要合理：根据业务特点调整阈值
  2. 定期更新：用户价值会变化，需要定期重新分层
  3. 结合业务理解：不要只看数据，要结合业务场景
  4. 验证效果：分层后要验证运营效果
