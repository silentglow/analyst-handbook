基础属性标签

数据来源

05 / BEHAVIORAL FEATURES

行为特征标签

数据来源

用户行为日志

行为特征标签反映用户的动态行为模式，包括活跃特征、消费特征和互动特征。与基础属性不同，行为标签需要持续更新，以反映用户最新的行为变化。

06 / PREFERENCE FEATURES

偏好特征标签

偏好特征标签揭示用户的潜在消费倾向，包括品类偏好、风格偏好、价格偏好和时间偏好。这些标签是预测用户未来行为的重要依据。

PYTHON 
def get_category_preference(user_id):
    """计算用户的品类偏好"""
    orders = get_user_orders(user_id)

    # 统计各品类购买金额
    category_amount = orders.groupby('category')['amount'].sum()
    total_amount = category_amount.sum()

    # 计算各品类占比
    category_ratio = category_amount / total_amount

    # 找出偏好品类（占比>20%）
    preferred = category_ratio[category_ratio > 0.2].index.tolist()

    return {
        'preferred_categories': preferred,
        'category_distribution': category_ratio.to_dict()
    }
PYTHON 
def get_price_preference(user_id):
    """计算用户的价格偏好"""
    orders = get_user_orders(user_id)

    # 统计各价格区间购买次数
    price_bins = [0, 100, 300, 500, 1000, float('inf')]
    price_labels = ['低价', '中低价', '中价', '中高价', '高价']

    orders['price_level'] = pd.cut(
        orders['unit_price'],
        bins=price_bins,
        labels=price_labels
    )

    price_distribution = orders['price_level'].value_counts(normalize=True)

    # 价格敏感度
    discount_rate = orders['discount_amount'].sum() / orders['original_amount'].sum()
    price_sensitivity = '高敏感' if discount_rate > 0.3 else '低敏感'

    return {
        'main_price_level': price_distribution.idxmax(),
        'price_sensitivity': price_sensitivity,
        'price_distribution': price_distribution.to_dict()
    }

08 / APPLICATION

画像应用场景

用户画像的最终价值在于落地应用。以下是三个核心应用场景：个性化推荐、精准营销和用户分层。

应用场景一：个性化推荐

PYTHON 
def get_personalized_recommendations(user_id):
    """基于用户画像的个性化推荐"""
    profile = get_user_profile(user_id)
    recommendations = []

    # 基于品类偏好推荐
    for category in profile['preference']['preferred_categories']:
        items = get_hot_items(category, price_level=profile['preference']['price_level'])
        recommendations.extend(items[:5])

    # 基于风格偏好推荐
    style = profile['preference']['style_preference']
    style_items = get_style_items(style)
    recommendations.extend(style_items[:3])

    return recommendations

应用场景三：用户分层

PYTHON 
def segment_users():
    """基于用户画像的用户分层"""
    users = get_all_users()
    segments = {
        '高价值用户': [],      # 高消费+高忠诚
        '潜力用户': [],        # 中消费+高活跃
        '价格敏感用户': [],    # 高敏感+中消费
        '低价值用户': [],      # 低消费+低活跃
    }

    for user in users:
        profile = get_user_profile(user['user_id'])

        if profile['value']['consume_level'] == '高' \
           and profile['value']['loyalty_level'] == '高':
            segments['高价值用户'].append(user)
        elif profile['behavior']['active_level'] == '高活跃':
            segments['潜力用户'].append(user)
        elif profile['preference']['price_sensitivity'] == '高敏感':
            segments['价格敏感用户'].append(user)
        else:
            segments['低价值用户'].append(user)

    return segments

09 / KEY FINDINGS

关键发现

发现 1

用户画像需要多维度

基础属性提供静态特征，行为特征提供动态特征，偏好特征提供预测能力，价值特征提供评估依据。四个维度缺一不可，共同构成完整的用户认知。

发现 2

标签需要持续更新

用户行为与偏好持续变化。画像需要建立定期更新机制，确保标签的时效性和准确性。

发现 3

画像应用场景广泛

从个性化推荐到精准营销，从用户分层到产品优化，用户画像的价值在于连接数据与业务决策，让每一次运营动作都有据可依。
