CHAPTER 03

叁LTV模型介绍

LTV（Lifetime Value）即用户生命周期价值，指一个用户在与企业关系的整个生命周期内，为企业创造的总价值。

方法一：简单估算法

LTV = ARPU × 用户生命周期长度
ARPU = 总收入 / 总用户数（平均每用户收入）
用户生命周期长度 = 1 / 流失率

方法二：历史数据法

LTV = Σt=1T 用户在第t期的贡献
把用户从获取到流失的所有贡献加总

方法三：预测模型法

LTV = Σt=1T 预测未来第t期贡献 × 折现因子
需要预测用户未来的行为

柒LTV预测模型

小林尝试构建LTV预测模型，用用户前30天的行为预测未来LTV。关键特征包括首单金额、访问频次、品类数等。

特征 相关系数 判断
首单金额 0.65 核心特征
前30天购买频次 0.58 重要
前30天访问次数 0.52 重要
品类数 0.45 参考
是否会员 0.38 参考

简化版预测模型代码：

PYTHON 
def predict_ltv(user):
    """基于用户前30天行为预测LTV"""
    base_ltv = 1000  # 基准LTV

    # 首单金额调整
    if user.first_order_amount > 500:
        base_ltv *= 2.5
    elif user.first_order_amount > 300:
        base_ltv *= 1.8
    elif user.first_order_amount > 100:
        base_ltv *= 1.0
    else:
        base_ltv *= 0.5

    # 访问频次调整
    if user.visit_count_30d > 10:
        base_ltv *= 1.3
    elif user.visit_count_30d > 5:
        base_ltv *= 1.1

    # 会员状态调整
    if user.is_member:
        base_ltv *= 1.5

    return base_ltv

CHAPTER 13

拾叁方法论总结

LTV（Lifetime Value）模型通过计算用户在整个生命周期内为企业创造的总价值，评估获客投资回报，指导投放决策和用户运营策略。

LTV计算步骤：

  • 1 计算ARPU（平均每用户收入）
  • 2 计算流失率（用户流失比例）
  • 3 计算生命周期（1 / 流失率）
  • 4 计算LTV（ARPU × 生命周期）

LTV/CAC比率标准：

LTV/CAC 评估 建议
< 1 亏损 停止获客，优化成本
1 - 3 低效 优化获客策略
3 - 5 健康 维持现状
> 5 高效 增加获客预算

适用场景：

  • ✓ 投放决策 — 评估渠道价值
  • ✓ 用户运营 — 用户分层运营
  • ✓ 产品定价 — 定价策略制定
  • ✓ 企业估值 — 企业价值评估
注意事项
  • • LTV是预测值：实际价值可能有偏差
  • • 分群体计算：不同群体LTV差异大
  • • 定期更新：LTV会随时间变化
  • • 结合其他指标：LTV 需要结合回收周期与留存判断
