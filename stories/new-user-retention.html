三、分析方法：同期群分析

Cohort Analysis —— 追踪用户生命周期的利器

📖 同期群分析定义

同期群分析（Cohort Analysis）是将用户按"同期"分组，追踪各组用户在后续时间段的行为变化。

同期群：在同一时间段内完成相同行为的用户群体。

例如：

  • 2024年1月注册的用户是一个同期群
  • 2024年2月注册的用户是另一个同期群

同期群分析的价值

⏱

排除时间干扰

不同时期的用户分开分析，避免新老用户混在一起掩盖真实问题

📈

发现趋势

用户质量是在变好还是变差？同期群对比能给出清晰答案

🚯

定位问题

哪个时期的用户留存有问题？精准定位到具体时间节点

四、第一步：计算新用户留存率

明确指标定义，是分析的第一步

留存率定义：某日注册的用户，在后续N天仍然活跃的比例。

留存率 = （第N天仍活跃的用户数 / 注册用户总数）× 100%

小林写了一段 Python 代码来计算留存率：

retention.py 
import pandas as pd

# 计算留存率
def calculate_retention(df, cohort_date, retention_day):
    """
    df: 用户行为数据
    cohort_date: 注册日期
    retention_day: 留存天数（1=次日，7=7日，30=30日）
    """
    # 获取该同期群的用户
    cohort_users = df[df['register_date'] == cohort_date]['user_id'].unique()

    # 计算retention_day后仍活跃的用户数
    target_date = cohort_date + pd.Timedelta(days=retention_day)
    active_users = df[df['action_date'] == target_date]['user_id'].unique()

    # 计算留存率
    retained = len(set(cohort_users) & set(active_users))
    retention_rate = retained / len(cohort_users)

    return retention_rate

十四、方法论总结

掌握同期群分析，让数据讲述用户的故事

📖 同期群分析

同期群分析将用户按时间维度分组，追踪各同期群在后续时间段的行为变化，用于发现用户质量趋势和定位问题时期。

同期群分析的步骤

1

确定同期群定义

按注册时间/首单时间分组，明确分组维度

2

计算留存率

各同期群在后续时间段（次日/7日/30日）的留存

3

构建留存矩阵

可视化留存变化，使用热力图等图表展示

4

对比分析

不同同期群之间的差异，发现趋势和异常

5

找出原因

为什么某些同期群表现差？结合业务事件分析

适用场景

📊

留存分析

分析用户留存变化趋势

🧪

效果评估

评估产品/运营改动效果

👥

用户质量分析

分析不同时期用户质量

🔀

A/B 测试

对比不同策略的效果

⚠️ 注意事项
  • 同期群定义要合理：根据业务特点选择分组维度
  • 时间窗口要一致：确保可比性
  • 样本量要足够：太小没有统计意义
  • 结合业务理解：数据变化要有业务解释
