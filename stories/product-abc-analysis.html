Chapter 03

分析方法：ABC分类法

基于帕累托原理的经典分类管理方法

ABC分类法定义

ABC分类法是一种基于帕累托原理（二八法则）的分类方法，将商品按重要性分为三类。其核心思想是：少数关键商品贡献了大部分价值。

累计占比 = Σ(xi) / Σ(xN)  (xi为第i个商品的销售额，按降序排列)
类别 销售额占比 SKU占比 特征 管理策略
A类 70% 10-20% 核心商品 重点管理、精细化运营
B类 20% 30% 次要商品 常规管理
C类 10% 50% 一般商品 简化管理、考虑淘汰
注意事项
  • 分类指标要合理，需根据业务目标选择（销售额/销量/毛利）
  • 阈值可调整，不同业务阈值可能不同（如A类70%/80%）
  • 分类需定期更新，商品结构会随时间变化
  • 建议结合其他维度（如XYZ稳定性）进行综合分析
聚焦重点
把精力放在最重要的商品上
差异化
不同类别商品不同策略
资源优化
合理分配采购、库存、营销资源

SQL 
SELECT
    product_id,
    product_name,
    category,
    SUM(sales_amount) as total_sales,
    SUM(sales_quantity) as total_quantity,
    COUNT(DISTINCT order_id) as order_count
FROM sales
WHERE sale_date BETWEEN '2024-01-01' AND '2024-03-31'
GROUP BY product_id, product_name, category
ORDER BY total_sales DESC;
Python 
import pandas as pd

# 按销售额排序
df = df.sort_values('total_sales', ascending=False)

# 计算累计销售额和累计占比
df['cumulative_sales'] = df['total_sales'].cumsum()
df['cumulative_ratio'] = df['cumulative_sales'] / df['total_sales'].sum()

# ABC分类
def abc_classify(row):
    if row['cumulative_ratio'] <= 0.7:
        return 'A'
    elif row['cumulative_ratio'] <= 0.9:
        return 'B'
    else:
        return 'C'

df['abc_class'] = df.apply(abc_classify, axis=1)

XYZ分类定义

XYZ分类法按销量稳定性对商品进行分类，使用销量波动系数（变异系数CV）作为判断标准。

CV = σ / μ  (σ为销量标准差，μ为销量均值)

业务建议

短期行动与长期机制相结合

短期建议

1. A类商品策略

  • 保证库存充足，避免断货
  • 重点营销推广
  • 优化商品详情页

2. C类商品策略

  • 清仓促销，降低库存
  • 停止补货
  • 逐步淘汰

3. 库存优化

  • AX类：设置安全库存
  • CZ类：停止补货，清理库存
长期建议

1. 建立商品分类管理体系

  • 定期进行ABC分类
  • 动态调整商品策略
  • 建立预警机制

2. 优化采购策略

  • A类：精准预测，及时补货
  • B类：常规采购
  • C类：减少采购或停止

3. 建立淘汰机制

  • 定期评估C类商品
  • 设置淘汰标准
  • 及时清理滞销品
注意事项
  • 清理C类商品时注意避免一次性大量清仓冲击价格体系
  • 淘汰前需确认是否有忠实用户群体
  • AX类商品需防范供应链风险

核心方法：ABC分类法

ABC分类法是基于帕累托原理的分类管理方法，通过计算累计占比将对象分为A（核心）、B（次要）、C（一般）三类，实现差异化管理和资源优化配置。

Rk = Σ(Si) / Σ(SN) × 100%  (Si为第i个对象的关键指标值，降序排列)
