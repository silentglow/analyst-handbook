# 数据分析师面试速通课

> 用数据讲故事，用逻辑做策略

## 🚀 在线访问

直接打开 `index.html` 即可，或部署到 GitHub Pages：

1. Fork / Clone 本仓库
2. 进入 Settings → Pages → Source 选 `main` 分支
3. 访问 `https://你的用户名.github.io/仓库名/`

## 📁 结构

```
├── index.html          # 主页（P1 从零到一搞定业务问题）
├── articles/           # 文章目录（待扩展）
└── README.md
```

## ✨ 特性

- **零依赖** — Tailwind CDN 加载，无需构建
- **纯静态** — GitHub Pages 免费托管
- **响应式** — 手机、平板、桌面自适应
- **动态特效** — 滚动渐显、毛玻璃卡片、打字机效果、背景光斑

## 🎨 自定义

编辑 `index.html` 中 Tailwind config 的颜色变量：
```js
colors: {
  surface: { 900: '#06070a' },  // 背景色
  accent: { cyan: '#5eead4' },  // 强调色
}
```
